# Исключения после правил CRS

Файлы `*.conf` отсюда подключаются последними — после всех правил CRS.

Типичное применение: корректировка итогового anomaly score, правила на
response-фазу, собственные детекты, которые должны видеть результат работы CRS.

Диапазон ID для собственных правил: 1000000–1999999.

## Про 00-placeholder.conf

Не удаляйте его, пока в каталоге нет ваших правил: ModSecurity падает
с ошибкой `Not able to open file`, если `Include` с маской `*.conf`
не нашёл ни одного файла.

Свои правила кладите отдельными файлами — порядок подключения алфавитный,
поэтому удобно нумеровать: `10-...`, `20-...`.
